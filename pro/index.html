01

Selected work

✓AWeekly SOX reporting

A weekly control report that runs end to end

Problem
A report supporting 15 Key controls depended on manual filtering, pivot refreshes, and a hand-kept distribution list.
Built
A VBA module that applies the business rules, refreshes the certified pivots, builds recipients from current data, and stages the email for review.
Safeguard
Trend and dashboard views sit structurally apart from certified figures, so a derived number can never override a certified one.
ΣQuarterly attestation

An attestation that collects its own audit evidence

Problem
A quarterly attestation behind 13 monitoring controls was a chase, and the evidence was rebuilt after the fact.
Built
A builder workbook and two VBA modules that generate the survey pack and send response files to 71 recipients across 3 business areas.
Result
The evidence is a byproduct of the workflow instead of a separate cleanup step.
✓≈Process improvement

Roughly 80% off a monthly audit review

Problem
A recurring audit response and timeliness review ate most of a day, and a broken macro forced workarounds.
Built
Redesigned the template, automated the build and formatting steps, and restored the macro.
Result
About 80% less handle time, measured before and after.
✓Control design

Retiring controls is part of the job too

Finding
Three Key controls were testing activity outside the risk they were meant to cover.
Action
Documented the design gap and worked it through to retirement.
Result
Removed from the annual certification cycle, so effort goes where the risk is.
ΣRules-gated tooling

A template builder that will not release incomplete work

Problem
A manual template process where errors carried real client and legal exposure.
Built
With the business: a 10-sheet workbook and VBA module with 22 rules traced to governing documents and 16 defects logged with root cause.
Result
A colleague now owns a follow-on build on the same pattern.
02

How I work

Fix the class of error

When a report went out with stale recipients, I rebuilt the list from live data and added a check before send, instead of just correcting the list.

Report the real number

On a Lean Six Sigma pilot, I retired a favorable figure of my own because it mixed comparison bases. The corrected number was less flattering and far more defensible.

Documentation ships with the tool

Every build comes with a maintainer guide and a plain-language walkthrough, so someone who was not in the room can run it and audit it.

Maintainable beats clever

I built a reporting app in React, then rebuilt it in VBA on purpose, because that is what the team can keep running.
